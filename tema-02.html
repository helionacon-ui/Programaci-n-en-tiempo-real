C++ moderno: de los objetos a la concurrencia · Tema 2

La biblioteca estándar: string, vector y map

C++ moderno: de los objetos a la concurrenciaProgramación

Desde cero

Objetivo: usar los contenedores y las funciones de la STL que entran en el examen, con la hoja de referencia de clases delante.

  • La STL es lo que hace productivo a C++: contenedores, iteradores y algoritmos ya escritos y probados. En el examen se entrega una hoja de referencia con las operaciones de string, vector, map y compañía, así que no hay que memorizar firmas, pero sí saber cuál usar y qué cuesta cada una.
  • string es un vector de caracteres con operaciones de texto: size, substr, find, insert, erase, concatenación con + y comparación con los operadores habituales. La constante string::npos es lo que devuelve find cuando no encuentra nada: compararla es el error clásico.
  • vector es un array que crece. Acceso por índice en tiempo constante, inserción al final amortizada constante, inserción o borrado en medio \(O(n)\). Es el contenedor por defecto: si dudas, vector.
  • map guarda pares clave-valor ordenados por clave, con búsqueda, inserción y borrado en \(O(\log n)\). unordered_map es una tabla hash: \(O(1)\) de media pero sin orden. El operator[] de un map crea la entrada si no existe, lo que es comodísimo para contar cosas y peligrosísimo si sólo querías consultar.
  • Los iteradores son la forma de recorrer cualquier contenedor con la misma sintaxis. begin() apunta al primero y end() a uno más allá del último: por eso el bucle es it != v.end() y nunca <=.
  • Los algoritmos de <algorithm> trabajan sobre rangos de iteradores: sort, find, count, accumulate (en <numeric>), for_each, transform.
  • La entrada y salida de ficheros usa ifstream y ofstream, que se comportan como cin y cout. Para leer línea a línea, getline(f, linea); para leer palabra a palabra, f >> palabra. Un ifstream en un if vale false si el fichero no se pudo abrir, y el bucle de lectura se escribe while (getline(f, linea)).

Explicación ampliada

Los contenedores: quién guarda qué

La biblioteca estándar (STL) te da estructuras ya hechas. string: texto con operaciones (size, substr, find, insert, erase). vector: una lista que crece sola, con acceso rápido por posición. map: pares clave→valor ordenados por clave (ideal para contar palabras). Conviene saber la diferencia entre v[i] (rápido, pero no comprueba límites: fuera de rango es comportamiento indefinido) y v.at(i) (lanza una excepción out_of_range). Las posiciones empiezan en 0; find devuelve string::npos si no encuentra nada.

Recorrer, ordenar y contar

Para recorrer un contenedor, el bucle de rango: for (const auto &x : v). Para ordenar: sort(v.begin(), v.end()). Para contar elementos de una frase se usa un map<string,int>: m[palabra]++ crea la entrada con 0 si no existía y suma 1. Trampa clásica: m["x"] crea la clave si no existe; para consultar sin crear se usa m.count("x") o m.find("x"). Al recorrer un map salen siempre ordenados por clave (orden alfabético para strings), y cada elemento es un par con .first (clave) y .second (valor).

Desarrollo teórico a fondo

1. La biblioteca estándar

  • std::string: cadenas que gestionan su memoria. Se concatenan con + y se comparan con ==.
  • std::vector: vector dinámico con push_back, size() y acceso por índice.
  • std::map: diccionario ordenado clave-valor, con búsqueda logarítmica.
Cuidado. Acceder a v[i] fuera de rango no lanza excepción: es comportamiento indefinido. v.at(i) sí comprueba el rango.
∴Iteradores

Un iterador generaliza el puntero. Los contenedores lo ofrecen con begin() y end(), que marca el final sin incluirse. Un bucle for (auto x : v) recorre todos los elementos.

Método paso a paso

  1. Elige el contenedor por la operación que más repitas: recorrer o indexar → vector; buscar por clave → map; contar apariciones → map<clave,int>.
  2. Para leer un fichero: abre, comprueba que se abrió, lee con getline en un while, procesa cada línea y cierra.
  3. Para trocear una línea usa stringstream con >>, o find + substr en bucle si el separador no es un espacio.
  4. Para contar con un map: m[clave]++. No hace falta comprobar si existe: operator[] la crea con 0.
  5. Para consultar sin crear usa count o find, nunca operator[].
  6. Comprueba siempre el resultado de find contra npos o contra end() antes de usarlo.

Trampas típicas

  • Comparar el resultado de s.find(...) con -1 o con 0. Hay que compararlo con string::npos, y ojo: una ocurrencia en la posición 0 es un resultado válido, así que if (s.find(x)) está mal.
  • Usar m[clave] para consultar un map y crear sin querer una entrada vacía, que además cambia el tamaño del map.
  • Guardar iteradores o referencias a elementos de un vector y seguir haciendo push_back: al crecer, el vector puede reubicarse y esos iteradores quedan inválidos.
  • Recorrer con it <= v.end(). end() apunta más allá del último: se usa !=.
  • Borrar elementos de un contenedor dentro de un bucle de rango. Hay que usar el iterador que devuelve erase.
  • Olvidar que leer con >> deja el salto de línea en el buffer, de modo que el getline siguiente lee una línea vacía.

Problema resuelto

Enunciado

Un fichero texto.txt contiene un texto cualquiera. Escribe un programa que cuente cuántas veces aparece cada palabra y muestre las palabras que aparecen más de una vez, en orden alfabético, junto con su número de apariciones. Las palabras se separan por espacios y hay que ignorar mayúsculas y los signos de puntuación.

✓Ver solución paso a paso

Este es el ejercicio tipo de PBO, y casi todo el trabajo lo hace el map.

#include <iostream> #include <fstream> #include <string> #include <map> using namespace std; // Pasa a minúsculas y quita lo que no sea letra string normalizar(const string &s) { string r; for (char c : s) if (isalpha(static_cast<unsigned char>(c))) r.push_back(tolower(static_cast<unsigned char>(c))); return r; } int main() { ifstream f("texto.txt"); if (!f) { cerr << "No se pudo abrir el fichero\n"; return 1; } map<string,int> cuenta; string palabra; while (f >> palabra) { // >> ya trocea por espacios string p = normalizar(palabra); if (!p.empty()) cuenta[p]++; // crea con 0 y suma } f.close(); for (const auto &par : cuenta) // el map ya está ordenado if (par.second > 1) cout << par.first << ": " << par.second << endl; return 0; }

Por qué está bien elegido cada elemento.

  • f >> palabra trocea por espacios y saltos de línea sin que tengamos que hacer nada: es más corto que getline + stringstream, que también valdría.
  • map y no unordered_map porque el enunciado pide orden alfabético: el map ya lo da gratis al recorrerlo. Con unordered_map habría que volcar a un vector y ordenar.
  • cuenta[p]++ aprovecha que operator[] crea la entrada con valor 0. Aquí sí queremos ese comportamiento.
  • El const auto & del bucle evita copiar cada par; par.first es la clave y par.second el valor.
  • Las funciones isalpha y tolower reciben un int y se les pasa el carácter convertido a unsigned char para evitar problemas con los acentos.

Coste. Leer \(n\) palabras con una inserción \(O(\log k)\) cada una, siendo \(k\) el número de palabras distintas: \(O(n\log k)\). El recorrido final es \(O(k)\).

Variante habitual del examen: en lugar de contar, guardar en el map la frase que empieza por cada letra y usarlo para cifrar o descifrar un mensaje. Es el mismo esqueleto: abrir fichero, leer línea a línea, rellenar el map, recorrer.

Ejercicios resueltos

Intenta cada uno antes de desplegar la solución.

Ejercicio 1 · Operaciones de string

Con string s = "programacion"; ¿qué devuelven s.substr(3,4), s.find("ra") y s.find("z")?

✓Ver solución paso a paso

Índices: p0 r1 o2 g3 r4 a5 m6 a7 c8 i9 o10 n11. substr(3,4) toma 4 caracteres desde el 3: «gram». find("ra") = 4 (la primera «ra» empieza en el 4). find("z") = string::npos (no está).

Ejercicio 2 · Contar palabras con map

Con map<string,int> m; se hace m[w]++ para cada palabra de «a b a c b a». ¿Qué imprime un recorrido?

✓Ver solución paso a paso

a aparece 3 veces, b 2 y c 1. El map las da por orden de clave: a 3, b 2, c 1. Si se hubiese consultado m["d"] sin más, se habría creado d 0.

Ejercicio 3 · Ordenar y acceder fuera de rango

vector<int> v{5,3,8,1}; Tras sort, ¿qué contiene? ¿Qué pasa con v.at(4) y con v[4]?

✓Ver solución paso a paso

Ordenado: 1 3 5 8. Los índices válidos son 0–3. v.at(4) lanza out_of_range (se puede capturar con try/catch). v[4] no comprueba: lee memoria que no es del vector (comportamiento indefinido: puede dar basura o hundir el programa).

string::npos. Hay que compararlo con eso, nunca con −1 ni con 0.

2¿Qué hace m[clave] si la clave no existe en un map?

La crea con el valor por defecto. Para consultar sin crear se usa count o find.

3¿Cuándo usar map y cuándo unordered_map?

map si necesitas las claves ordenadas; unordered_map si sólo necesitas buscar rápido.

4¿Qué coste tiene insertar en medio de un vector?

\(O(n)\): hay que desplazar todos los elementos siguientes.

5¿Por qué el bucle con iteradores usa != y no <=?

Porque end() apunta a uno más allá del último elemento; nunca se desreferencia.
