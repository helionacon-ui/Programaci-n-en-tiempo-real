Lógica difusa y kNN

Tiempo real: planificación y algoritmosTiempo real

Desde cero

Objetivo: implementar un controlador difuso de Sugeno y un clasificador por vecinos más próximos, que son los dos algoritmos propios de la asignatura.

  • La lógica difusa (Zadeh, 1965) sustituye la pertenencia binaria por un grado de pertenencia entre 0 y 1. Una temperatura de 24 ºC puede ser «templada» con grado 0,7 y «caliente» con grado 0,3 a la vez. Sirve para expresar control en forma de reglas del lenguaje natural, sin necesitar un modelo matemático de la planta.
  • Un sistema difuso tiene tres etapas: fuzzificación (convertir la entrada numérica en grados de pertenencia a los conjuntos), inferencia (evaluar las reglas) y defuzzificación (volver a un número, el valor crisp).
  • Las funciones de pertenencia más usadas son triangulares y trapezoidales, porque se calculan con cuatro restas y una división. También se usan gaussianas y sigmoides.
  • En el modelo de Mamdani la salida de cada regla es también un conjunto difuso, y hay que defuzzificar agregando conjuntos (por centro de gravedad). En el modelo de Sugeno, que es el que se usa en la asignatura, la salida de cada regla es una función de las entradas, normalmente una constante, y la defuzzificación es una simple media ponderada. Por eso Sugeno es mucho más barato y es el habitual en controladores empotrados.
  • Las reglas tienen la forma «SI \(x\) es A Y \(y\) es B ENTONCES \(z=k\)». El Y se implementa con el mínimo (o el producto) de los grados de pertenencia, y el O con el máximo.
  • kNN (k nearest neighbours) es un clasificador que no entrena nada: guarda todos los ejemplos y, para clasificar uno nuevo, calcula su distancia a todos, se queda con los \(k\) más cercanos y asigna la clase mayoritaria entre ellos.
  • Dos detalles decisivos en kNN: hay que normalizar los atributos, porque si uno va de 0 a 1000 y otro de 0 a 1, el primero domina completamente la distancia; y \(k\) conviene que sea impar en problemas de dos clases, para evitar empates.
  • El coste de kNN es \(O(n\cdot d)\) por consulta, con \(n\) ejemplos y \(d\) atributos: es barato de «entrenar» (nada) y caro de consultar, justo al revés que la mayoría de los clasificadores.
  • Los dos algoritmos aparecen en la asignatura como ejercicios de programación con la STL: leer un fichero de datos, rellenar un vector de estructuras, recorrerlo calculando distancias o grados de pertenencia y ordenar con sort. El algoritmo es la excusa; lo que se evalúa es el C++.

Fórmulas y conceptos que hay que saber

  • Funciones de pertenencia:
\[\mu_{\triangle}(x;a,b,c)=\max\left(0,\ \min\left(\frac{x-a}{b-a},\ \frac{c-x}{c-b}\right)\right)\] \[\mu_{\square}(x;a,b,c,d)=\max\left(0,\ \min\left(\frac{x-a}{b-a},\ 1,\ \frac{d-x}{d-c}\right)\right)\]
  • Operadores: Y → \(\min(\mu_1,\mu_2)\) (o \(\mu_1\cdot\mu_2\)) · O → \(\max(\mu_1,\mu_2)\) · NO → \(1-\mu\).
  • Defuzzificación de Sugeno (media ponderada):
\[z^{*}=\frac{\displaystyle\sum_{i=1}^{R} w_i\,z_i}{\displaystyle\sum_{i=1}^{R} w_i}\]
  • donde \(w_i\) es el grado de activación de la regla \(i\) y \(z_i\) su salida.
  • Centro de gravedad (Mamdani, para comparar): \(z^{*}=\dfrac{\int z\,\mu(z)\,dz}{\int \mu(z)\,dz}\).
  • Distancias para kNN:
\[d_{\text{euclídea}}=\sqrt{\sum_{j=1}^{d}(x_j-y_j)^2},\qquad d_{\text{Manhattan}}=\sum_{j=1}^{d}|x_j-y_j|\]
  • Normalización (imprescindible): \(x'_j=\dfrac{x_j-\min_j}{\max_j-\min_j}\in[0,1]\).
  • Ordenar por distancia con la STL:
sort(v.begin(), v.end(), [](const Ejemplo &a, const Ejemplo &b) { return a.dist < b.dist; });

Método paso a paso

  1. Para un controlador difuso: define los conjuntos de cada entrada (normalmente 3 o 5: bajo, medio, alto), escribe la tabla de reglas, calcula los grados con las funciones de pertenencia, el peso de cada regla con el mínimo y la salida con la media ponderada.
  2. Comprueba la partición: en una partición bien hecha, para cualquier entrada la suma de los grados de pertenencia vale 1 y hay como mucho dos conjuntos activos.
  3. Para kNN: lee los datos, normaliza cada atributo, calcula la distancia del punto nuevo a todos, ordena, toma los \(k\) primeros y vota.
  4. Elige \(k\) impar en dos clases y prueba varios valores: \(k\) pequeño se ajusta al ruido, \(k\) grande suaviza de más.
  5. En C++, guarda cada ejemplo en una struct con sus atributos, su clase y un campo para la distancia; usa sort con una lambda, y un map<string,int> para contar los votos.

Trampas típicas

  • No normalizar antes de calcular distancias en kNN. Es el error que más distorsiona el resultado.
  • Elegir \(k\) par en un problema de dos clases y tener que inventar un criterio de desempate.
  • En Sugeno, sumar las salidas sin dividir por la suma de los pesos: hay que hacer la media ponderada.
  • Olvidar las reglas con peso 0. No estorban, pero si todas salen 0 la división es \(0/0\): hay que tratar ese caso.
  • Diseñar conjuntos que dejan huecos (zonas donde ninguna regla se activa) o que se solapan demasiado.
  • En las funciones triangulares, dividir por \(b-a\) cuando \(a=b\) (triángulo con un lado vertical). Hay que tratar ese caso aparte.
  • Confundir Mamdani con Sugeno al defuzzificar: con Sugeno no hay centro de gravedad de conjuntos.

Problema resuelto

Enunciado

Diseña un controlador difuso de Sugeno para un ventilador. La entrada es la temperatura, con tres conjuntos triangulares: fría (10, 15, 20), templada (18, 23, 28) y caliente (26, 32, 38) ºC. Las reglas dan una potencia de 0, 50 y 100 %. Calcula la salida para 19 ºC y para 27 ºC, y explica cómo lo programarías.

✓Ver solución paso a paso

Para 19 ºC. Grados de pertenencia:

\[\mu_{\text{fría}}(19)=\frac{20-19}{20-15}=\frac{1}{5}=0{,}20\] \[\mu_{\text{templada}}(19)=\frac{19-18}{23-18}=\frac{1}{5}=0{,}20\] \[\mu_{\text{caliente}}(19)=0\quad(19<26)\]

Media ponderada de Sugeno:

\[z^{*}=\frac{0{,}20\cdot0+0{,}20\cdot50+0\cdot100}{0{,}20+0{,}20+0}=\frac{10}{0{,}40}=\boxed{25\ \%}\]

Para 27 ºC.

\[\mu_{\text{fría}}(27)=0,\qquad \mu_{\text{templada}}(27)=\frac{28-27}{28-23}=0{,}20,\qquad \mu_{\text{caliente}}(27)=\frac{27-26}{32-26}=\frac{1}{6}=0{,}1667\] \[z^{*}=\frac{0{,}20\cdot50+0{,}1667\cdot100}{0{,}20+0{,}1667}=\frac{10+16{,}67}{0{,}3667}=\frac{26{,}67}{0{,}3667}=\boxed{72{,}7\ \%}\]

Tiene sentido: a 19 ºC el ventilador va al mínimo y a 27 ºC a casi tres cuartos.

Implementación.

#include <iostream> #include <vector> #include <algorithm> using namespace std; struct Triangular { double a, b, c; double grado(double x) const { if (x <= a || x >= c) return 0.0; if (x < b) return (x - a) / (b - a); if (x > b) return (c - x) / (c - b); return 1.0; // x == b } }; struct Regla { Triangular conjunto; double salida; }; double sugeno(const vector<Regla> &reglas, double x) { double num = 0.0, den = 0.0; for (const Regla &r : reglas) { double w = r.conjunto.grado(x); // peso de la regla num += w * r.salida; den += w; } return (den > 1e-9) ? num / den : 0.0; // evitar 0/0 } int main() { vector<Regla> reglas = { { {10, 15, 20}, 0.0 }, // SI fría -> 0 % { {18, 23, 28}, 50.0 }, // SI templada -> 50 % { {26, 32, 38}, 100.0 } // SI caliente -> 100 % }; for (double t : {19.0, 23.0, 27.0, 35.0}) cout << t << " ºC -> " << sugeno(reglas, t) << " %" << endl; }

Salida: 19 ºC → 25 %, 23 ºC → 50 %, 27 ºC → 72,7 %, 35 ºC → 100 %.

Lo que hace bueno a este código no es el algoritmo, que son diez líneas, sino el diseño: la función sugeno no sabe cuántas reglas hay ni qué significan, y añadir un cuarto conjunto es añadir una línea al vector. Si el enunciado pidiera dos entradas (temperatura y humedad), bastaría con que cada regla tuviera dos conjuntos y el peso fuese el mínimo de los dos grados.

El esqueleto de kNN es igual de corto:

struct Ejemplo { vector<double> x; string clase; double dist; }; string knn(vector<Ejemplo> datos, const vector<double> &nuevo, int k) { for (Ejemplo &e : datos) { // 1. distancias double s = 0.0; for (size_t j = 0; j < nuevo.size(); ++j) s += (e.x[j]-nuevo[j]) * (e.x[j]-nuevo[j]); e.dist = sqrt(s); } sort(datos.begin(), datos.end(), // 2. ordenar [](const Ejemplo &a, const Ejemplo &b){ return a.dist < b.dist; }); map<string,int> votos; // 3. votar entre los k primeros for (int i = 0; i < k && i < (int)datos.size(); ++i) votos[datos[i].clase]++; return max_element(votos.begin(), votos.end(), [](const auto &a, const auto &b){ return a.second < b.second; })->first; }

Fíjate en que datos se pasa por valor: necesitamos una copia porque vamos a ordenarla, y no queremos destrozar el orden del conjunto original. Es uno de los poquísimos casos en los que pasar por valor es la decisión correcta, y saber justificarlo vale puntos.

Autoevaluación

Responde antes de desplegar.

1¿Qué tres etapas tiene un sistema difuso?

Fuzzificación (grados de pertenencia), inferencia (evaluar reglas) y defuzzificación (volver a un número).

2¿En qué se diferencian Mamdani y Sugeno?

En Mamdani la salida de cada regla es un conjunto difuso y hay que agregarlo; en Sugeno es una función o constante y la defuzzificación es una media ponderada. Sugeno es mucho más barato.

3¿Cómo se implementan el Y y el O entre grados de pertenencia?

El Y con el mínimo (o el producto) y el O con el máximo.

4¿Cuál es la fórmula de defuzzificación de Sugeno?

\(z^{*}=\dfrac{\sum w_i z_i}{\sum w_i}\): media de las salidas ponderada por el grado de activación de cada regla.

5¿Por qué hay que normalizar los atributos en kNN?

Porque la distancia la domina el atributo de mayor rango: sin normalizar, uno que vaya de 0 a 1000 anula a otro que vaya de 0 a 1.

6¿Qué coste tiene clasificar un ejemplo con kNN?

\(O(n\cdot d)\) por consulta: no hay entrenamiento, pero hay que recorrer todos los ejemplos cada vez.
